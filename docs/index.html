Conector AWS Cost Explorer

{{ULTIMA_ACTUALIZACION}}

¿Qué es y para qué sirve?

Este conector permite al agente de Ruvic consultar costos y uso de tu cuenta de AWS: costo total por servicio, costo agregado por período, y previsión de gasto futuro. Es 100% de solo lectura.

OperaciónQué hace
cost.get_cost_by_serviceCosto total agrupado por servicio de AWS
cost.get_cost_by_periodCosto agregado por día o mes
cost.get_cost_forecastPrevisión de gasto para un rango futuro

Prerrequisitos

  • Una cuenta de AWS con Cost Explorer habilitado (se activa una vez desde la consola de Billing).
  • Acceso a la consola de AWS IAM para crear un usuario dedicado.

Configuración en el fabricante

  1. Activá Cost Explorer si no lo está.

    En la consola de AWS Billing → Cost Explorer, activalo (puede tardar hasta 24h en mostrar datos la primera vez).

  2. Crea un usuario IAM dedicado.

    En IAM → Usuarios → Crear usuario. Solo acceso programático.

  3. Adjuntá la policy de solo lectura de costos. 
    {
  "Version": "2012-10-17",
  "Statement": [
    {
      "Effect": "Allow",
      "Action": ["ce:GetCostAndUsage", "ce:GetCostForecast"],
      "Resource": "*"
    }
  ]
}
  4. Genera las claves de acceso.

    Guardá el Access Key ID y el Secret Access Key — el secreto solo se muestra una vez.

Permisos requeridos

PermisoPara qué sirve
ce:GetCostAndUsageCosto por servicio y por período
ce:GetCostForecastPrevisión de gasto
Nota Cost Explorer no admite restricción por Resource (siempre "*"), pero al ser un servicio 100% de solo lectura no hay riesgo de escritura.

Configuración en Ruvic

Entrá a Settings → Conectores, buscá AWS Cost Explorer y pulsá Configurar. Completá el Access Key ID y el Secret Access Key generados.

Probar conexión — la plataforma consultará el costo de los últimos 7 días para confirmar credenciales.

Verificación

  1. Test de conexión exitoso.

    "Probar conexión" debe responder con éxito.

  2. Prueba mínima con el agente.

    Pedile:

    "¿Cuál es mi gasto de AWS por servicio este mes?"

    El agente debe devolver el desglose real por servicio.

Solución de problemas

Mensaje / síntomaCausa probable y solución
"Credenciales inválidas o sin permiso IAM suficiente"Access Key inválida/rotada, o falta el permiso ce:GetCostAndUsage/ce:GetCostForecast.
Todos los montos en ceroCost Explorer recién activado (puede tardar 24h en mostrar datos), o la cuenta genuinamente no tuvo gasto en el rango consultado.
Error al pedir previsión de fechas pasadasget_cost_forecast solo acepta rangos a futuro; usá get_cost_by_period para el pasado.
El conector aparece "Sin configurar" tras guardarAlgún campo obligatorio quedó vacío. Completá Access Key ID y Secret Access Key.

Preguntas frecuentes y notas de seguridad

¿El agente puede modificar mi facturación o pagar algo?

No. Cost Explorer es un servicio 100% de solo lectura; no existe ninguna acción de escritura ni de pago en su API.

¿Dónde queda guardado el Secret Access Key?

Como secreto en el almacén de credenciales de la plataforma. La interfaz nunca vuelve a mostrarlo.

Rotación de credenciales

Recomendado cada 90 días: generá un Access Key nuevo en IAM y actualizalo en el formulario.

Buenas prácticas Usá un usuario IAM dedicado solo para consulta de costos; no le des ningún otro permiso adicional, aunque Cost Explorer en sí no admita restricción por Resource.
